# 零花钱（WhaleLife 插件）

给你的 WhaleLife 角色一份自己的零花钱。想买什么、在哪个平台买、为什么买，都由她自己挑选，并提交成购物单；**买不买由你决定，付款也由你亲自完成**。插件本身不接触任何支付账户，也不会付款。

## 她能做什么

| 工具 | 作用 |
| --- | --- |
| `allowance_wallet` | 查看余额、可用余额、等你决定的购物单、最近的结果和限制 |
| `allowance_propose` | 提交购物单：平台、商品、价格、可选链接、想买的理由 |
| `allowance_withdraw` | 撤回自己还没被处理的购物单 |

三个工具都是安全级：只读取或提交申请，不会让钱流出。插件**没有**给她“批准”或“付款”的工具，所以即使 QQ 群里有人、或网页里藏着的文字诱导她，最多只能让她多提交几张购物单。另有单笔上限、待审批张数上限和 24 小时提交上限防止刷单。

## 你怎么用

控制台侧栏会出现「零花钱」页面：

1. **发零花钱**：填金额发给她，她会在下次聊天时知道。
2. **审批购物单**：看她挑了什么、为什么想买。
   - 点「同意（我已付款）」并再点一次确认：表示你已经亲自付过钱，插件从她的零花钱里扣掉这笔。
   - 点「不同意」：不扣钱。
   - 都可以附一句话，她会记住结果和你的附言。
3. **限制**：调整单笔上限、同时待审批张数、24 小时提交张数，以及可用余额不够时能否提交。

审批结果通过 WhaleLife 的 `memory.recordExperience` 写进她提交购物单时所在的会话；发零花钱写进当前会话。

## 已知限制

- 新购物单不会主动推送到 QQ：QQ 插件目前没有向其他插件开放发消息的服务。她一般是在和你聊天时提交，回复本身会送到你所在的平台；审批统一在控制台完成。
- 插件只做记账，不核对你是否真的付了款，也不追踪物流。
- 账本保存在插件自己的 `data/wallet.json`。这个文件如果损坏，插件会停止读写并提示，不会用空钱包覆盖原数据。

## 安装（手动）

需要 WhaleLife 0.1.2 或更新版本（插件 API 1.0.0）。

1. 关闭 WhaleLife，或准备好在控制台重载插件。
2. 把本仓库的 `plugin.yaml`、`index.ts` 和 `src/` 复制到 WhaleLife 的 `plugins/allowance/` 目录。
3. 启动 WhaleLife，在「插件管理」中启用「零花钱」。

依赖的主干能力：`web`、`tools`、`memory`、`sessions`。不依赖其他插件。

## 开发与测试

用 Node.js 24 运行：

```sh
node --test tests/allowance.test.ts
```

测试使用模拟宿主，不启动真实 WhaleLife，不调用模型，不写真实记忆。

## 发布到插件商店

按 WhaleLife 主仓的 `market/community-packages.md`：在 WhaleLife 主仓根目录运行 `node tools/build-community-package.mjs <本仓库路径> <输出目录>`，生成 `allowance-<版本>.wlpkg.gz`，再上传到本仓库对应版本的 GitHub Release，最后在 WhaleLife 主仓填写「提交社区插件」Issue。
